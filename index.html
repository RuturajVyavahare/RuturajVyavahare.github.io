PROJECT 02 // FINITE STATE MACHINE

FPGA-Based Traffic Light Controller with Priority System

Developed an FSM-driven four-way traffic controller in Verilog featuring emergency-vehicle priority overrides triggered via Basys 3 board switches. Implemented strict priority arbitration and a fail-safe clearance sequence.

Verilog HDL FSM Architecture Priority Encoder AMD Vivado Basys 3 Artix-7
  • Full 4-direction intersection control across North, South, East, and West thoroughfares.
  • Emergency vehicle override input with priority arbitration: North > South > East > West.
  • Fail-safe clearance sequence: ALL-RED → EMERGENCY GREEN → ALL-RED → NORMAL OPERATION.
  • Parameterized emergency duration (EMERGENCY_TIME = 10s) configurable directly in RTL.
  • Verified state machine transitions in Vivado Simulator and implemented on Basys 3 hardware.

PROJECT 03 // DIGITAL SECURITY & LOGIC

Smart Digital Lock System

Developed a sequential four-digit digital security lock in Verilog HDL. In the physical Basys 3 FPGA hardware implementation, four-digit passwords are sequentially input using 4-bit board switches and a push-button confirmation mechanism, driving multiplexed 7-segment display PASS/FAIL feedback, real-time attempt indicators, and a three-attempt persistent security lockout.

Verilog HDL Digital Logic 4-Bit Switch Input 7-Segment Multiplexing AMD Vivado Basys 3 Artix-7
  • Hardware Input Architecture: Sequential 4-digit password entry using 4-bit physical switches and push-button latching on Digilent Basys 3.
  • 7-Segment Feedback: Multiplexed 4-digit 7-segment display outputs real-time alphanumeric PASS and FAIL verification status.
  • LED Status Indicators: Active door unlock LED with 3 dedicated per-attempt failure indicator LEDs.
  • Persistent Hardware Lockout: Three consecutive incorrect entries trigger an FSM lockout state (state <= LOCKOUT) that halts all further entry until an explicit hardware reset.
  • Password Authorization: Reprogramming flow requiring authentication of the existing PIN before saving a new PIN.
